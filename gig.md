## Description

Want your own online store? I will build you a complete, working e-commerce
website — not a template demo, a real store you can start selling with.

**What your store includes:**
- Beautiful product catalog with search, categories and sorting
- Product detail pages with related products
- Shopping cart and checkout with Cash on Delivery
- Customer sign-up / login and order history
- Admin dashboard — add, edit and delete products, view all orders,
  change order status, see total sales and low-stock alerts
- 16 sample products already loaded, so you can see it working on day one
- Clean, mobile-friendly design that works on phone, tablet and desktop
- Full source code, database and step-by-step run instructions

**Tech used:** Python Flask, SQLite (MySQL version included), HTML / CSS / JavaScript.
No monthly fees, no paid plugins, no licence costs.

**How it works:**
1. You place the order and tell me your shop name and the products you sell.
2. I set up the store with your branding and your products.
3. I show you a live demo, then deliver the complete source code with
   instructions to run it on your own computer or server.

Perfect for small shops, college projects, startups and anyone who wants to
start selling online fast.

## FAQs

**Q: Do I need to buy hosting or a domain?**
A: No — the store runs on your own computer for testing. For a live public
store you will need hosting, and I can deploy it for you in the Premium
package.

**Q: Can I add my own products?**
A: Yes. The admin panel lets you add, edit and delete products yourself,
no coding needed. In Standard and Premium I load your products for you.

**Q: Can this be changed to MySQL instead of SQLite?**
A: Yes — a MySQL version of the database is included, and Standard and
Premium include the MySQL setup.

**Q: Will it work on mobile?**
A: Yes, the design is responsive and works on phone, tablet and desktop.
